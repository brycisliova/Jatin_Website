Write in Markdown. Files starting with an underscore, and any note with `draft: true`,
are never published. Copy this file, rename it (for example `why-eyes-close.md`),
remove the `draft` line and the note appears on the site together with the **Notes** menu item.

## A heading

Paragraphs, *emphasis*, [links](https://example.org), lists and images all work.
Put images in `static/img/notes/` and reference them as `../../img/notes/figure.webp`.
